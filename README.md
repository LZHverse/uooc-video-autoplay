# 深大 UOOC 优课视频连播

适用于 UOOC 课程学习页的 Tampermonkey 用户脚本。它会尝试播放未完成的视频、设置静音和 2 倍速，并在视频结束后打开下一个未完成视频。章节测试不会自动作答；视频内测验出现时需要手动完成。

脚本已通过 JavaScript 语法检查及模拟页面测试，尚未在实际登录的课程页验证。课程是否记录学习进度、播放器是否允许 2 倍速，取决于 UOOC 网站本身。

## 安装

1. 在浏览器安装并启用 Tampermonkey。
2. 打开仓库中的 [uooc-video-autoplay.user.js](./uooc-video-autoplay.user.js)，点击 **Raw**，确认安装或更新。
3. 打开 `https://www.uooc.net.cn/home/learn/` 下的课程视频页。页面左上角应出现状态提示。

脚本默认静音、2 倍速。可在文件开头修改 `SPEED` 和 `MUTE` 常量。

## 排查

- **没有状态提示：** 先检查脚本是否已启用、地址是否在 `/home/learn/` 路径下，再刷新课程页。开发者工具控制台的过滤器也可能隐藏日志。
- **显示 1X 或移开鼠标就暂停：** 确认页面已加载本仓库的脚本。状态提示会显示播放或错误信息。
- **播放中断：** 查看页面左上角状态及浏览器控制台中的 UOOC 日志。遇到视频内测验时需手动完成。
- **课程进度未更新：** 等待网站同步，并在课程目录中核实完成状态；本脚本不直接修改服务端进度。

## 已知限制

- 依赖 UOOC 当前页面的 Angular 目录数据和 Video.js 播放器结构；网站改版后可能失效。
- 无法保证浏览器或网站允许自动播放、倍速播放及后台播放。
- 未对章节测试自动作答。
